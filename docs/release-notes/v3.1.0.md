# Release Notes - v3.1.0

## ✨ What's New
- **Meet Scout, your mascot companion**: A friendly CC0-licensed character (Kenney adventurer art) walks onto the page with reminders to drink water, rest your eyes, take a break, or stop for the day. Each reminder type can be switched on or off in the popup.
- **Video blocker for ignored reminders**: If you keep watching for 45 seconds after Scout's water, eye-strain, or break reminder, the player is covered and the video paused. A 20-second countdown runs before you can resume.
- **Daily watch limit block**: Once the stop-watching reminder triggers, the player is blocked until you deliberately choose **Watch 5 more min**.
- The block stays in place across YouTube page navigation and in fullscreen, and respects reduced-motion settings.

## 🛠️ Bug Fixes
- **Accurate watch time with multiple tabs**: Only a video that is actually playing in the focused tab and window is counted. Background tabs, paused videos, and unfocused windows no longer add time, and two tabs never double-count.
- **No more duplicate reminders**: Each reminder fires once, in the tab you are watching, instead of once per open YouTube tab. Reminders no longer repeat after a reload, page navigation, or browser worker restart.
- **Smoother mascot walk**: Frames now share one canvas and baseline, so the walk no longer jitters.
- **Hover previews can no longer bypass the block**: The blocker targets the main player, not thumbnail previews.

## 📦 Technical Updates
- Replaced the previous copyrighted mascot art with CC0 assets; license files are included under `mascots/`.
- Added dependency-free Node regression tests for watch-time counting, reminder de-duplication, and escalation.
- Added a developer-only Test Lab tab (development builds only) for previewing reminders and blocks.
